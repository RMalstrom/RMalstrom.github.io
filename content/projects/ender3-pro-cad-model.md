## Objective
Demonstrate Inventor proficiency by modeling an accurate Ender 3 Pro.

## Tools & Setup
- **Hardware:** Ender 3 Pro, calipers
- **Software:** Autodesk Inventor

## Process
1. Tore down the Ender 3 Pro to create a parts list
2. Created a full part list of needed files
3. Modeled every part using both real-world measurements and online schematics
4. Assembled all parts to create the overall design
